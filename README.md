## What Is Design Calculators?

Design Calculators is a single web toolkit that consolidates hands-on engineering math across electrical, mechanical, and instrumentation work. Instead of jumping between scattered references, you stay in the browser and move through the values you need for design, study, or quick checks.

The audience is broad: practicing engineers, learners, and anyone who wants clear, focused calculators during technical work on desktop or mobile.

## FAQ

### Who should use Design Calculators?

Anyone working with electrical, mechanical, or instrumentation calculations—professionals, students, or enthusiasts.

### Is a desktop install required?

No. Everything is a browser-facing HTML application; open it in a compatible browser.

### How are updates obtained?

Prefer the hosted build for the newest published release, or refresh a clone with:

```bash
git pull
```

### Will the tools run offline?

Yes, if you keep a complete local copy and open or serve it locally, and the calculators you use do not rely on external network assets.

### A page fails to open—what next?

Make sure the download finished, try a local static server, and inspect the browser developer console for missing files or load errors.

### How do I report a bad result or UI problem?

File a repository issue that names the calculator category, the inputs you used, what you expected, and what actually appeared.
